# Leave and Absence Management API

Basic Express.js backend for the bachelor thesis project.

## Install dependencies

```bash
cd server
npm install
```

## Start the server

```bash
cd server
npm start
```

The server runs on port 5000.

## Test the API

Root endpoint:

```bash
curl http://localhost:5000/
```

Health endpoint:

```bash
curl http://localhost:5000/api/health
```
